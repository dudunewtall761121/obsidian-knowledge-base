# 项目索引 · 说明

> 收录团队所有在运行/已归档项目的元信息索引卡。**只存元信息，不存项目内容。**
> 维护规则见 [[../README|知识库维护手册]] · 总览见 [[00-项目总览|项目总览]]

## 1. 项目索引是什么、不是什么

**是什么**
- 每个项目一张索引卡，记录路径、状态、负责人、关键文档链接
- 跨项目检索的入口：启动任务前先查项目索引，确认项目归属与现状
- 项目状态的唯一登记处（active / paused / planning / archived）

**不是什么**
- 不是项目文档的副本（原文件留在项目目录内，索引卡只放链接）
- 不是任务产出
- 不记录项目内部的技术细节、代码、设计稿

---

## 2. 索引卡标准格式

模板见 [[../00-模板/项目索引卡模板|项目索引卡模板]]。

```markdown
---
type: project
tags: [项目/active]
created: 2026-11-09
updated: 2026-11-09
status: active
owner: 项目负责人
path: "D:\\Work Space\\项目名"
repo: ""
---

## 一句话简介
## 当前阶段
## 关键文档（只放 file:/// 链接）
## 最近更新
## 关联知识
```

**必填项**：type、tags、created、updated、status、owner、path、一句话简介、关键文档。

---

## 3. 谁写、谁更新

| 角色 | 职责 |
|---|---|
| 项目负责人 | 项目启动/状态变更时更新自己项目的索引卡与总览 |
| DOT 连接器 | 每周巡检：检查路径有效性、状态是否过期、关键文档链接是否失效 |

---

## 4. 状态定义

| 状态 | 含义 | 标签 |
|---|---|---|
| `planning` | 规划中，未开始执行 | `#项目/planning` |
| `active` | 正在推进中 | `#项目/active` |
| `paused` | 暂停，有恢复计划 | `#项目/paused` |
| `archived` | 已完结或长期搁置 | `#项目/archived` |

状态变更须在「最近更新」段记录日期与原因。

---

## 5. 维护检查清单（每周一 DOT 执行）

- [ ] 所有 active 项目的 `updated` 距今天数 ≤ 14 天
- [ ] 所有索引卡的 `path` 指向的目录存在
- [ ] 「关键文档」链接可点击、无 404
- [ ] `00-项目总览.md` 与各索引卡 status 一致
- [ ] 无状态为 `paused` 超过 90 天未更新的项目
