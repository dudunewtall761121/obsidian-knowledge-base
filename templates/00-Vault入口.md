## 📌 使用须知

1. **Agent 读写前必须 `git pull --rebase`，写完 `git push`**；
2. 任务产出留在工作台任务目录，提炼后的知识进 `03-知识库/`；
3. 知识库内容须过审，无来源、不可复用、超 300 字的卡片不收；
4. 遇到 Git 冲突不自动 merge，生成 `.conflict` 文件待人工处理。
